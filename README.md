# ÉLIXIR — цифровий парфумерний бутик

> «Аромат, який розповідає твою історію».

Портфоліо-проєкт: преміальний український магазин оригінальної люксової парфумерії з інтерактивним 3D-шоурумом.
Увесь інтерфейс українською, ціни в гривнях; назви брендів і ароматів — оригінальні.

**Шрифти:** Playfair Display (заголовки) · Jost (текст), лише латиниця й кирилиця.

**Стек:** React 18 · Vite · TypeScript · Tailwind CSS · Three.js · React Three Fiber · Drei · Framer Motion · GSAP ScrollTrigger · Lenis · Zustand

## Можливості

- Кінематографічний hero з 3D-флаконом (обертання мишею/перетягуванням, частинки, анімація при скролі)
- Колекція з 50 реальних люксових і нішевих ароматів (24 бренди) з посторінковим показом: фільтри за групою й брендом, пошук (назва, бренд, ноти), сортування
- Сторінка товару: 3D-перегляд 360° з інерцією й зумом, вибір об'єму, кількість, піраміда нот, характеристики
- Пробники 2 / 5 / 10 мл до кожного аромату (ціна рахується від ціни за мл, формула в `src/data/meta.ts`)
- Фільтри «Для неї / Для нього / Унісекс», ціна (подвійний повзунок), сезон, нота з автопідказкою, акорд
- «Схожі аромати» на сторінці товару — за спільними нотами й акордами
- Інтерактивне колесо ароматів: 5 груп × 14 акордів, обертання до вибраного сектора, перехід до відфільтрованої колекції
- Консультант з вибору аромату (кнопка-крапля в куті): розуміє опис українською — для кого, нагода, настрій, «не солодке», бюджет, сезон, ноти, «схоже на Aventus», уточнення «а дешевше?», «покажіть ще»
- Кошик (localStorage), список бажань, повноекранний пошук, оформлення демо-замовлення з валідацією
- Квіз «Discover your scent», бестселери, бренди, про бутик, розсилка, футер з політиками
- Адаптивність: desktop / laptop / tablet / mobile; лінива загрузка 3D, фолбек без WebGL

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build          # production-збірка в dist/
npm run build:single   # один самодостатній HTML-файл: dist-single/index.html (працює офлайн)
```

## Консультант: офлайн і ШІ-режим

За замовчуванням працює **офлайн-консультант** (`src/lib/consultant.ts`) — детермінований аналізатор запитів і підбір за
каталогом, без мережі (працює й в однофайловому HTML).

**ШІ-режим (Claude)** вмикається на Netlify, якщо сайт розгорнуто з Git (не через Drop — там немає функцій):

1. Site settings → Environment variables: `ANTHROPIC_API_KEY` = ваш ключ API Anthropic, `VITE_AI_CONSULTANT` = `1`.
2. Передеплойте сайт. Функція `netlify/functions/consultant.mts` (`/api/consultant`) викликає модель `claude-opus-5-5`
   з каталогом у системному промпті (кешується) і відповіддю за JSON-схемою; рекомендації — лише з каталогу.
3. Якщо ШІ недоступний (немає ключа, ліміт, помилка) — автоматично відповідає офлайн-консультант.

Вартість: кожне повідомлення — це запит до API (каталог ~10–12 тис. токенів, з кешуванням значно дешевше).
Публічна функція не має захисту від зловживань — за потреби додайте ліміт запитів.

## Тестування

`scripts/qa.mjs` — наскрізний QA-сценарій на Playwright (перевірки: навігація, картки, фільтри, сортування, пошук,
3D-обертання мишею і дотиком, кошик, wishlist, checkout-валідація, квіз, бренди, розсилка, форма консьєржа, політики,
deep-link, збереження стану; desktop / mobile / tablet; збір помилок консолі).

```bash
npm run dev
node scripts/qa.mjs ./qa-shots
```

## Важливо

- 3D-флакони — **стилізовані інтерпретації**, згенеровані з параметрів, а не офіційні моделі брендів.
- Піраміди нот та факти позначені як *Official* (за даними будинків); описи й оцінки стійкості/шлейфу — *Editorial*.
- Ціни — орієнтовні роздрібні ціни в Україні (UAH), легко змінюються.
- Оформлення замовлення — **демо**: оплата не проводиться, замовлення ніде не передається. Для реальних продажів потрібен бекенд і платіжний провайдер.
- Назви брендів і продуктів є торговими марками їхніх власників.

Деплой на Netlify: `netlify.toml` уже налаштовано (`npm run build` → `dist`).
